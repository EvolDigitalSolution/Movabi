This is an empty-list result, expected before the first subaccount. It is not evidence that collection subaccounts are unsupported, nor proof of create permission or merchant identity. Authentication, permission and technical failures remain errors; no raw provider errors are returned. The operator diagnostic reports emptyList, zero records, creationPermissionVerified=false and recreationPermitted=false. A future diagnostic is optional, not an activation prerequisite.

Status does not call the provider list or require a pre-existing account. An approved first-time driver receives available=true, state=not_started and reconcileOnly=false, opening the existing form. Creation is completed only after matching retrieval of the provider reference, destination fingerprint, frozen defaults and operation metadata. Authentication/permission/technical lookup errors expose safe category codes and still cannot cause another create. No manual pre-creation is allowed.
